# Avisos de jogos e licenças — Resolvei Games

Os jogos **Jungla Run**, **Stellar Defense** e **Operação Delta** são experiências originais criadas para o Resolvei Games. Os personagens, cenários e efeitos visuais desses três jogos são desenhados proceduralmente no navegador e não usam sprites ou áudio extraídos de franquias comerciais.

## Conquista Mundial

O jogo de estratégia territorial incorporado ao Resolvei Games é baseado no projeto independente [Risk — Global Domination](https://github.com/DJLougen/risk-game), de DJLougen, distribuído sob licença MIT.

O código do projeto foi adaptado para a interface em português brasileiro. O jogo é uma implementação de estratégia territorial no estilo Risk; não é uma reprodução oficial do jogo WAR da Grow.
